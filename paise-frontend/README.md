# Paise frontend (static)

1. Open `index.html` and set `API_URL` (near the top of the script) to your Render URL, e.g. `https://paise-api.onrender.com`.
2. Deploy to Vercel: push this folder to GitHub and import it in Vercel (Framework: Other, no build command), or run `npx vercel` inside the folder.
3. Copy your Vercel URL into the backend's `FRONTEND_URL` variable on Render and redeploy.
4. Open the app, enter your `APP_PASSWORD` once per device.
